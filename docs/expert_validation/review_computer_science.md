### Concept descriptions

**Complexity Analysis** (`computer_science.algorithms.complexity_analysis`)  
Big-O notation and analyzing the efficiency of algorithms.  
*Objectives:* Determine the time complexity of an algorithm using Big-O notation.

**Searching Algorithms** (`computer_science.algorithms.searching_algorithms`)  
Linear and binary search strategies for locating data.  
*Objectives:* Implement linear and binary search and identify when each is appropriate.

**Sorting Algorithms** (`computer_science.algorithms.sorting_algorithms`)  
Common algorithms for ordering a collection of data.  
*Objectives:* Implement and compare at least two different sorting algorithms.

**Arrays** (`computer_science.data_structures.arrays`)  
Storing and accessing ordered collections of data.  
*Objectives:* Use arrays to store and iterate over ordered collections of data.

**Introduction to Graphs** (`computer_science.data_structures.graphs_intro`)  
Representing networks of relationships as nodes and edges.  
*Objectives:* Represent a network as a graph and choose an appropriate traversal strategy.

**Linked Lists** (`computer_science.data_structures.linked_lists`)  
A linear data structure built from nodes connected by references.  
*Objectives:* Implement basic operations (insert, delete, traverse) on a linked list.

**Stacks and Queues** (`computer_science.data_structures.stacks_queues`)  
LIFO and FIFO data structures and their applications.  
*Objectives:* Implement and apply stacks and queues to solve ordering problems.

**Trees** (`computer_science.data_structures.trees`)  
Hierarchical data structures and common tree traversal methods.  
*Objectives:* Implement tree traversal algorithms and apply them to hierarchical data.

**Boolean Logic** (`computer_science.foundations.boolean_logic`)  
Logical operators (AND, OR, NOT) and truth tables.  
*Objectives:* Construct and evaluate truth tables for boolean expressions.

**Number Systems** (`computer_science.foundations.number_systems`)  
Binary, decimal, and hexadecimal representations of numbers.  
*Objectives:* Convert numbers between binary, decimal, and hexadecimal representations.

**Control Flow** (`computer_science.programming.control_flow`)  
Conditionals and loops that determine a program's execution path.  
*Objectives:* Use conditionals and loops to control a program's execution path.

**Functions and Procedures** (`computer_science.programming.functions_procedures`)  
Organizing code into reusable, named blocks with inputs and outputs.  
*Objectives:* Write functions with well-defined inputs and outputs to organize code.

**Recursion** (`computer_science.programming.recursion`)  
Functions that solve a problem by calling themselves on smaller subproblems.  
*Objectives:* Write and trace recursive functions with correct base cases.

**Variables and Data Types** (`computer_science.programming.variables_and_types`)  
How programs store and represent data using variables and types.  
*Objectives:* Declare variables of appropriate types for a given programming task.

**Discrete Math Foundations** (`computer_science.theory.discrete_math_foundations`)  
Sets, logic, and relations that underpin computer science theory.  
*Objectives:* Apply set theory and logical reasoning to simple discrete math problems.

**Object-Oriented Programming** (`computer_science.theory.object_oriented_programming`)  
Organizing code around objects that bundle data and behavior.  
*Objectives:* Design a small program using classes, objects, and encapsulation.
